開啟
1. 將 ZIP 完整解壓到同一資料夾。index.html 與所有資源檔均位於根目錄。
2. Windows 執行 START-WINDOWS.cmd；使用電腦既有 Python 3 啟動本機 HTTP。
   或使用既有 Node：node serve.cjs。此包不安裝軟體。
3. 電腦瀏覽器開啟 http://127.0.0.1:8894/ 。請勿直接點 ZIP 內的 index.html。
4. 手機與電腦連同一 Wi-Fi，電腦執行 PHONE-LAN.cmd，在手機開啟視窗顯示的區域網路網址，並橫放。
   電腦伺服器須保持執行；本程式不更改防火牆。離線 ZIP 本身不能直接執行網頁模組。
5. 在伺服器視窗按 Ctrl+C 結束。本包沒有公開部署。

操作
WASD／方向鍵或觸控搖桿移動；按住攻擊連續普攻，放開停止。技能頁可按「施放選定技能」。
畫面提供紅水、綠水、回城、背包及 GM 按鈕。地圖頁可查看區域及配置。
固定原版死亡騎士，站姿為使用者選定的原 GIF 第 39 幀（零基索引 38）。沒有變身與金色發光。
八向移動、左右鏡像顯示；原圖只有一組視角，並非八向原畫。
普攻只用原 overhead 0–4 幀，於第 2 幀單次命中。基礎攻速／移速 1.5 倍。
綠水持續 300 秒，移速再乘 1.20、攻速再乘 1.25；重喝刷新時間、不疊加倍數。
