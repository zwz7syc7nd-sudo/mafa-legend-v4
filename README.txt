荒境・重生 R6.0.0 — 3D 單機 GM 試玩版

這是一個可操作的 WebGL 2 網頁遊戲，不是影片或背景截圖。
角色、怪物、房屋、樹木、武器與地面是程式建立的 3D 網格。
玩家的腿、膝蓋、手臂、武器、披風各自具有動作；怪物有巡邏、追擊、攻擊、受擊、死亡狀態。
美術方向為風格化 3D，不是先前寫實概念圖的商業級美術。

這包已包含所有執行檔，沒有 CDN、外部模型、付費素材、登入或伺服器需求。
網站部署仍需要 HTTPS 網頁空間。

更新現有網站
1. 在 iPhone「檔案」解壓縮本 ZIP。
2. 使用你已有的 GitHub 專案 mafa-legend-v4 的 Upload files。
3. 一次選取本 ZIP 解壓出的所有檔案，在專案根目錄提交覆蓋。
4. 不要先刪除舊檔案，不要更改 index.html 的檔名，不要建立新的倉庫或 Vercel 專案。
5. Vercel 發布新提交後，用 Safari 開現有遊戲網址。
6. 畫面標題應為「荒境・重生」，左上角應顯示 R6 · 3D。看到這個才是本版。

重要：ZIP 不是可直接安裝的 iPhone App。不要在「檔案」預覽器裡執行 index.html。
本檔案交付不代表你的網站已自動更新。

操作
手機：左下搖桿移動；點地面會尋路；右下斬擊可長按。
烈火：前方強力斬擊，需要魔力，有冷卻。
旋風：周圍範圍攻擊，需要魔力，有冷卻。
衝刺：向面朝方向移動，有短暫無敵與冷卻。
藥水：恢復生命／魔力，有冷卻；不需要購買。
全圖自動：尋找可到達的怪物 → 尋路 → 戰鬥 → 拾取 → 下一區。
一輪 48 隻怪物全部擊敗後，等待 12 秒刷新全圖。
點小地圖或「地圖」可看完整世界，點世界地圖可尋路。
地圖下面的區域按鈕為 GM 傳送功能。
NPC 附近點選 NPC 可恢復生命與魔力。
背包中點物品，再按「穿戴這件裝備」。
GM 可生成自訂名稱、部位、品質、攻擊、防禦、暴擊與吸血的裝備。
開背包／GM／設定時戰鬥暫停，關閉後繼續。

鍵盤：WASD / 方向鍵移動；空白鍵攻擊；1 烈火；2 旋風；左 Shift 衝刺；F 自動；I 背包；Esc 關面板。

世界
224 × 224 公尺的連續地圖，並非一個螢幕。
燼火營地（安全區）、風嘯原野、翡翠密林、失落王庭、幽晶礦場、龍骨祭壇。
怪物包括灰脊荒狼、翠毒巨蛛、亡骨劍衛、幽晶守衛、赤獄領主。
建築、樹木、岩石、水面有碰撞限制；A* 尋路會避開阻擋物。

存檔與離線
每 12 秒、切離頁面、關閉面板時會嘗試本機存檔。
設定面板可匯出／匯入 JSON 存檔。清除網站資料可能刪掉本機進度，請先匯出備份。
關閉遊戲後不會繼續掛機。
已包含版本化離線快取程式，成功完成第一次線上快取後才能離線啟動。
本次環境未能完成 iPhone 離線重開測試，不把它列為已通過的實機功能。
