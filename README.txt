瑪法・烈焰戰紀 R9.4.0-six
橫屏 2.5D 單機動作遊戲 — 六階段整合版

更新方式
沿用原本 GitHub mafa-legend-v4。解壓本包後，把所有檔案直接放在 repository 根目錄，覆蓋同名檔案後一次提交。
不要直接上傳 ZIP 當遊戲，也不要多包一層資料夾。不要先刪除 index.html；本包所有素材要一併上傳。
這份沒有替你更新線上網站，也沒有替你重建 GitHub/Vercel。

手機操作
橫置手机後按「進入邊城」。左下搖桿移動，也可點地面尋路；右下破軍可長按，四主技能分兩頁，瞬影與補血獨立。
上方可開背包、地圖、技能、GM、設定。打開面板、直立、切到背景時暫停；關閉遊戲不會在背景掛機。
背包可分類、整理、穿戴、強化到+15。GM可改數值、解鎖技能與選擇四種既有外觀，不是輸入任意名字就產生新模型。
設定中可調鏡頭、接地陰影、音效；支援存檔匯出。請匯出JSON備份重要進度，避免瀏覽器清理資料後丟失。

鍵盤
WASD／方向鍵移動，Space 普攻，1–4主技能，Q技能翻頁，E瞬影，K技能書。實際遊戲按钮才是手機操作入口。

內容
224×224世界，六區，初始48隻怪物；Boss召喚可增加怪物數，死亡後按遊戲規則重生。
十技能：破軍斬、炎龍斬、半月橫掃、野蠻衝鋒、雷霆劍氣、旋風烈斬、戰神降臨、龍魂爆裂、護體戰氣、瞬影追殺。
角色的腿、膝、手臂、武器、肩甲、披風、光翼分層運動；怪物巡邏、追擊、攻擊、死亡；Boss預警與狂暴。

明確限制
美術是分層圖像骨架動畫，不是完整八方向逐幀原畫；多套裝備與怪物共享部分部件。並未達到參考概念圖的商業美術品質。
已有本地瀏覽器功能及快取程式單元測試，但未做實體iPhone效能和真正HTTPS離線重開驗收。詳見 TEST_REPORT.txt。
不要把語法通過或測試數量解讀為任何裝置都保證不出錯。
