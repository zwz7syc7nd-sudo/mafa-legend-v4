龍燼・戰魂 R8.0.1
橫屏單機 WebGL 2 動作 RPG

這是可操作的遊戲，不是影片，也不是一張背景圖片加上移動人物。
人物使用分件 3D 模型：上臂、前臂、腿、膝蓋、武器、披風分別參與動作。
地面、道路、城牆、樹木、怪物與裝備在 224 × 224 遊戲世界中渲染。

操作
橫向開啟。直向會顯示旋轉提示並暫停。
左下搖桿或點地面移動；右下攻擊可按住連斬，其餘技能點擊施放。
全圖自動按鈕啟動掃圖，手动搖桿會停止自動。
背包：點物品 → 穿戴這件裝備；開啟面板時戰鬥暫停。
GM：生成指定裝備或套裝、召喚 Boss、重新刷怪、調整測試能力。
設定：存檔、匯出／匯入存檔、鏡頭距離、音效、陰影及自動穿戴。
開始前已有一套高階外觀、初章平衡數值的裝備。延續 R7 存檔則保留原裝備。
舊存檔要查看新外觀：GM 裡選四套換裝，或正常取得／穿戴新裝備。

離線與存檔
首次必須由 HTTPS 網站載入；Service Worker 收齊本包資源後才可離線。
設定內會顯示離線安裝狀態。只把 HTML 存到「檔案」預覽不等於啟動網站遊戲。
真實 iPhone 離線重開未經本地端到端驗證，不能當作已驗收功能。
私密瀏覽或清除網站資料可能無法保留進度；重要角色請先匯出存檔。
換了網站網域，舊網域 localStorage 不會自動搬家；請使用匯出／匯入。

美術與測試範圍
實際成品是風格化 3D，仍與你先前核可的寫實概念圖有差距。
不是商業 MMORPG 原始素材，也不是多人連線遊戲。
本包有瀏覽器功能測試與 Service Worker 單元測試，詳見 TEST_REPORT.txt。
沒有實體 iPhone 的效能、耗電、完整離線安裝驗收，也沒有替你發布到 Vercel。

資產
材質與圖示由程式製作，裝備圖示由本版模型渲染。
遊戲沒有第三方 CDN、遠端模型或付費素材的執行期相依。
素材檔案必須與 index.html 一起上傳，不能只換 HTML。
