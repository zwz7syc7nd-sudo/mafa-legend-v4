燼土・龍魂 R7.0.0｜橫屏・暗黑換裝更新包

這是沿用 R6 的單機 WebGL 2 遊戲，不是概念圖或影片。
角色、四套盔甲、四種武器、怪物、建築、樹木均由即時 3D 網格構成。
美術是原創暗黑風格化 3D；不是之前生成的寫實概念圖，也不是商業《傳奇》的原始素材。

【更新既有 V4 通道】
1. 解壓這個 ZIP。
2. 將解壓後的全部檔案放到既有 mafa-legend-v4 儲存庫根目錄，同名覆蓋。
   不需要先刪除 index.html，不需要建立新的 repository 或新的 Vercel project。
   不要直接把 ZIP 檔當成網站首頁上傳，也不要把檔名改成 index.html.html。
3. 所有檔案一起 Commit。仍然使用原本的 GitHub → Vercel 發布通道。
4. 新版啟動頁會顯示「燼土・龍魂」及 R7。
本下載包不等於網站已經更新；這份檔案尚未由助理部署到你的帳號。

【操作】
本版只在橫屏時遊玩。直立會顯示旋轉提示並暫停人物與戰鬥；轉回橫向繼續。
介面適應不同橫屏長寬比，不把整個畫面硬拉伸為 16:9。
左下搖桿：360 度移動。點地面：尋路。右下：斬擊、烈火、半月旋斬、野蠻、藥水。
按住斬擊可連續普攻。「全圖自動」開啟跨區尋怪、戰鬥及拾取；手動推搖桿會取消自動。
右上：背包、地圖、GM、設定。面板開啟時戰鬥暫停，避免操作背包時被打死。
電腦也可用 WASD / 方向鍵移動、空白鍵普攻、1 / 2 技能、Shift 衝刺、F 自動、I 背包。

【地圖與戰鬥】
保留 224 × 224 遊戲單位的同一張連續世界，包含六區：
燼土邊城、枯骨荒原、腐影密林、鎮魂王庭、黑鐵礦場、赤獄龍壇。
每輪 48 隻怪物，含世界首領。怪物有巡邏、追擊、攻擊、受擊、倒地狀態。
人物腿、膝、肩、肘、武器與披風有獨立運動，不是整張 PNG 平移。
烈火、半月與野蠻有魔力或冷卻限制；傷害、暴擊、受擊、擊退與死亡直接作用於遊戲資料。
全圖清除後會開始新一輪刷怪，遊戲不是一段預錄播放。
本版另外修正障礙物邊緣的尋路起點、路線邊緣碰撞、卡住的掉落物拾取。

【角色裝備】
淬鐵、霜月、玄冥、赤霄四組盔甲／武器外觀。
高階胸甲會改變肩甲、頭盔、胸甲、腰甲、披風等模型及材質；武器是不同的 3D 網格。
新角色直接穿戴赤霄外觀的初章裝，數值為一般開局數值，不是開啟無敵或秒殺。
背包內可拖曳旋轉 3D 角色，點物品選擇裝備；自動穿戴可在設定切換。
GM 的四個套裝按鈕會真正生成並穿上裝備。
GM 可自訂名稱、部位、品質、攻擊、防禦、暴擊、吸血及外觀樣式。
「任意生成」指可建立自訂裝備數值；不是輸入任何名稱就即時生成無限種全新模型。
戒指和護符目前影響屬性，沒有獨立可見的手指／頸部飾品模型。

【存檔與離線】
使用相同網站來源時，R7 沒有存檔會讀取已有 R6 存檔，並在新鍵 mafa-reborn-r7 下儲存。
原 mafa-reborn-r6 鍵不會被刪除。v4／v5 圖片原型的舊存檔不是相同格式。
也可在設定匯出／匯入存檔 JSON。私密瀏覽或清除網站資料可能不保留本機存檔。
離線功能採用 Service Worker：首次需要成功在線載入並完成離線資源安裝。
設定面板會顯示離線資源狀態。不能把 iPhone「檔案」的 HTML 預覽當成遊戲執行環境。

【驗證與限制】
已在真正的 Chromium WebGL 2 渲染器啟動並跑完 21 項核心測試。
另用 8 組指定種子測試正常開局的自動清圖，全部清除 48 隻怪並走遍六區。
已測試數種橫屏視窗及直立暫停，並對 Service Worker 做獨立程式測試。
完整範圍與原始測試結果在 TEST_REPORT.txt、TEST_RESULTS.json。
未在實體 iPhone／Safari GPU 上測試，不宣稱已驗證實機幀率、溫度、耗電、瀏海安全區。
受測試環境網路限制，未完成瀏覽器 HTTPS Service Worker 安裝→離線啟動的端到端驗證。
這是一張大地圖的個人單機試玩版，沒有多人伺服器、商城付費、商業遊戲完整內容。
