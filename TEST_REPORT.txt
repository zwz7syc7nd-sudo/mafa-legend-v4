交付範圍
本輪以已存在且 CRC 驗證通過的 R9.3 整合包為基礎，依序完成六個工程階段。
這是可操作的單機 2.5D 動作遊戲整合版；不把概念圖當成遊戲截圖。
美術仍是分層裁切素材搭配關節變換。四套裝備共享部分素材，並非完整八方向手繪逐幀動畫，也未達參考圖的商業美術完成度。

測試環境與方法
Linux / Chromium 144.0.7559.96 / Playwright / Node.js v22.16.0。
在瀏覽器 page.set_content 執行交付的 HTML 與外部 JS/CSS，測試器將本地圖片與 rig JSON 對應為 data URL；實際使用正式遊戲的 Canvas 2D、tick、AI、傷害與面板程式。
未能透過瀏覽器網路導覽直接開本地伺服器（環境回覆 ERR_BLOCKED_BY_ADMINISTRATOR）；沒有繞過該限制。
觸控使用 CDP Input.dispatchTouchEvent，含開始、拖曳與取消；不是僅呼叫位移函式。
另以原有 requestAnimationFrame 排程實際運行，沒有加速該項測試。
自動清圖使用正式 tick，以 1/30 秒步進加速；秒數是遊戲模擬時間，不是 iPhone 幀率或玩家通關時間。
Service Worker 以 Node VM / 模擬 Cache、Request、Response、fetch 和事件做單元測試，不等於 HTTPS 安裝、飛航模式離線重開的端到端驗證。

本輪實際找到並修正的問題
1. NPC 與玩家共用動作診斷 key，NPC 覆蓋玩家关節記錄：分離 actor key。
2. 肩部與手肘攻擊角度互相抵消，刀尖揮動太小：調整手肘前伸，使刀尖與身體獨立變化，重跑命中及動作檢查。
3. 遠鏡頭採用過大的地塊可見範圍，造成不必要繪製與快取重建：改為投影四角精確剔除。最遠鏡頭靜止第二幀實測重建 0 塊；LRU 上限 64 塊。
4. 舊護符縮圖帶有原畫UI碎片：全部改為乾淨的独立護符圖示。
5. 版本分散會混到舊圖：HTML build meta、腳本、CSS、圖示、rig與SW資源查詢版本統一；完整安裝成功才寫入標記，缺檔不接管。
6. 重新裁切怪物頭與肢體、重做龍翼與龍頸，避免舊素材中的火焰岩石或重複龍臉。
